## 2025-04-03 - Avoid `setData` in property observer for derived state in WeChat Mini Programs
**Learning:** Calling `setData` inside a component property's `observer` to set derived state (like array lengths) triggers redundant secondary render cycles, which degrades performance in WeChat Mini Programs.
**Action:** Compute and use derived state directly in WXML templates (e.g., `{{list.length}}`) or pass it as computed inline properties (e.g., `data="{{listLength: list.length}}"`) to a `<template>` instead of setting it in the logical layer.
