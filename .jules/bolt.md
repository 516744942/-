## 2026-07-19 - Prevent Redundant secondary render cycles from derived states in observer
**Learning:** In WeChat Mini Programs, setting derived state like array lengths inside a component property's observer triggers redundant secondary render cycles. While it's best to compute derived state directly in WXML (e.g. `listLength: list.length`), if the derived state relies on intentional default `data` initializations (like `listLength: 1`) to prevent UI empty-state flashing before asynchronous loading, we must instead compute the fallback value (`const newLength = newVal ? newVal.length : 0;`) and wrap the `setData` call in a strict equality check (`if (this.data.listLength !== newLength)`).
**Action:** Avoid blind removal of `setData` in observers if a default state prevents UI regressions. Instead, use WXML derived props where safe, or wrap `setData` in a strict equality check where default `data` initializations are required.
