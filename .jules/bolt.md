## 2024-05-18 - WeChat Mini Program: Conditional setData for Derived State
**Learning:** In WeChat Mini Program components, updating derived state (like array lengths) inside property observers blindly triggers redundant render cycles when object references update but primitive values do not. Removing setData completely is preferred, but sometimes intentional default data initializations are used as UI hacks to prevent empty-state flashing prior to asynchronous data loading.
**Action:** When an observer must update derived state that cannot be cleanly removed, wrap the setData call in a strict equality check with safety null checks (e.g., `if (newVal && this.data.listLength !== newVal.length)`) to prevent redundant renders. For states that can be computed cleanly, compute them directly in the WXML template inline properties.
