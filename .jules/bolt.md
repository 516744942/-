## 2026-04-20 - Removed Redundant Observer `setData` in `rowscroll` Component
**Learning:** Found an unnecessary `setData({ listLength: newVal.length })` in a component property observer (`components/rowscroll/rowscroll.js`). In WeChat Mini Programs, putting derived properties like length into `setData` during an array observer triggers a redundant secondary render cycle, wasting performance. The appropriate fallback data object initialization to `1` (like the one present in `courselist.js`) is an acceptable hack for visual regressions, but updating length in an observer adds completely unnecessary overhead.
**Action:** When working on components rendering derived state, delete unnecessary `setData` properties from their `observer`s. Instead, pass the evaluated expression in the inline property definition (e.g., `data="{{...item, listLength: list.length}}"`) to keep the data bindings correct while skipping the redundant re-rendering cycle.
