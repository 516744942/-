## 2026-10-30 - Derived State Observer Optimization in WeChat Mini Programs
**Learning:** In WeChat Mini Programs, setting derived state (like array lengths) inside component observers via setData causes redundant render cycles across the logic-view bridge. However, simply removing setData and computing inline can cause UI regressions (flashing empty states) if the component relies on default data blocks (e.g. listLength: 1) during initial load.
**Action:** When optimizing derived state observers, check the initial data block. If a default initialization is used as a UI hack, compute the derived state and wrap the setData call in a strict equality check (e.g. if (this.data.listLength !== newLength)). If no default is used, completely remove the observer and compute the property directly in WXML or via template data parameters.
