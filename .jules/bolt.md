## 2026-04-28 - [Optimize redundant derived state setData in observers]
**Learning:** In WeChat Mini Program WXML, components sometimes map a derived state like `listLength` to template parameters via property observers triggering `setData`. This causes redundant secondary render cycles on every object reference update, even if length doesn't change.
**Action:** Compute derived state directly in the WXML template (e.g. `data="{{...item, listLength: list.length}}"`) and remove the observer's `setData`. If the initial `listLength` state must be preserved as a UI hack (e.g. `data: { listLength: 1 }`) to prevent empty-state flashing before async load, wrap the `setData` in the observer with a strict equality check (`if (this.data.listLength !== newVal.length)`) instead of removing it entirely.
