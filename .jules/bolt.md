## 2024-05-18 - Avoid Redundant SetData in Property Observers for Derived State
**Learning:** In WeChat Mini Programs, updating derived state (such as array lengths via `this.setData`) inside a component property's `observer` creates a secondary, redundant render cycle. This is an architectural performance bottleneck, especially in list components where this can fire frequently.
**Action:** Always avoid `setData` for simple derived properties (like `.length`) inside `observer`s. Instead, compute and use derived state directly in the WXML template (e.g., `{{list.length}}`) or pass it as inline computed properties inside templates (e.g., `data="{{listLength: list.length}}"`) to keep rendering in a single cycle. Caution: Maintain intentional initial data hacks (e.g. `listLength: 1`) to prevent empty-state flashing.
