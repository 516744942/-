## 2024-05-23 - WeChat Mini Program: Avoid redundant `setData` in `observer` for derived states
**Learning:** In WeChat Mini Program component property `observer`s, calculating derived states (like `newVal.length` for array properties) and updating them via `this.setData` introduces an unnecessary, secondary synchronous bridge serialization (from logic layer to view layer) during the component's data initialization/update phase. If a derived state is only used for UI rendering, it can be passed directly inside WXML via computed property definitions in templates (e.g., `data="{{...item, listLength: list.length}}"`) or just used as `{{list.length}}` directly.
**Action:** Always identify components with array properties executing `this.setData({ length: newVal.length })` in their observers, remove the redundant `setData` logic, remove the empty observer function completely to avoid WeChat watcher overhead, and update the WXML to access `.length` directly or via inline bindings.
