## 2026-08-16 - Optimize redundant setData calls in WeChat Mini Program components
**Learning:** Setting derived states (like list.length) within `observer` functions triggers expensive secondary render cycles. We can avoid this by computing the derived state directly in WXML (e.g., `list.length`) or wrapping the `setData` call in a strict equality check to prevent updates when the value hasn't changed. We must be careful not to remove default state initializations (like `listLength: 1`) that serve to prevent empty-state flashing.
**Action:** When working on WeChat Mini Programs, look for `setData` inside component observers. Replace them by computing properties directly in the `.wxml` file when possible, or wrap them in conditional checks (`if (this.data.X !== newX)`) if the initial property acts as an anti-flashing mechanism.
