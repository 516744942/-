## 2024-05-18 - WeChat Mini Program Performance: Redundant `setData` for Derived State
**Learning:** Using `setData` inside an `observer` to set derived state (like array `listLength: newVal.length`) triggers a redundant secondary render cycle whenever the array reference changes, even if the length is identical. Blindly removing it can cause visual regressions if the default `data` is used as a UI hack.
**Action:** When a derived state cannot be cleanly removed or computed directly in WXML, wrap the `setData` call in a strict equality check with safety null checks (e.g., `if (newVal && this.data.listLength !== newVal.length)`) to prevent redundant render cycles when object references update but primitive values do not. Ensure intentional default `data` initializations are preserved.
