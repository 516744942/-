## 2024-05-18 - Prevent Redundant Secondary Renders in WeChat Component Observers
**Learning:** Using `setData` inside an `observer` to set derived state (like array lengths) triggers an expensive, redundant secondary render cycle in WeChat Mini Programs. Furthermore, if `data` is initialized to default values (like `listLength: 1`) to act as a UI hack preventing empty-state flashing prior to data loading, blindly removing it can introduce visual regressions.
**Action:** Pass derived states like array lengths inline directly to templates in WXML (e.g., `data="{{...item, listLength: list.length}}"`) to eliminate the `setData` in JS completely. If a fallback must be maintained in JS for UI hacks, wrap the `setData` within a strict equality check (`if (this.data.listLength !== newLength)`) and ensure safe fallbacks (`newVal ? newVal.length : 0`).
